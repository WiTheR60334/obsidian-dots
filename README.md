# Obsidian Dots

Minimal, clean and performance-focused Arch Linux rice built around:

- Hyprland
- Caelestia Shell
- Quickshell
- Kitty
- Oh-My-Zsh

Designed with a dark obsidian aesthetic, smooth animations, and a modern system-monitoring workflow.

## Stack

| Component | Setup |
|---|---|
| OS | Arch Linux |
| WM | Hyprland |
| Shell | Zsh + Oh-My-Zsh |
| Terminal | Kitty |
| Shell UI | Caelestia |
| Widgets | Quickshell |
| Bootloader | rEFInd + UKI |
| GPU | NVIDIA |

---

## Features

- Minimal dark-green obsidian theme
- Custom Quickshell widgets
- GPU / CPU monitoring cards
- NVIDIA optimized Wayland setup
- Smooth Hyprland animations
- Custom fan monitoring widget
- Fast boot with UKI
- Clean terminal workflow
- Modern rice without bloated dependencies
